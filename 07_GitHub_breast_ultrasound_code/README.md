# Regional breast ultrasound validation

Companion code for “Posterior brightness in breast ultrasound: measurement availability, diagnostic increment and contour sensitivity across three datasets”. Authors: Yusong Wu and Jing Zhang. Corresponding author: Yusong Wu (yusongwu123@foxmail.com).

## Public datasets

Download data from their original providers and follow their terms and citation requirements:
- BUS-BRA: https://doi.org/10.5281/zenodo.8231412 ; documentation: https://github.com/wgomezf/BUS-BRA ; paper: https://doi.org/10.1002/mp.16812
- BrEaST / BREAST-LESIONS-USG: https://www.cancerimagingarchive.net/collection/breast-lesions-usg/ ; paper: https://doi.org/10.1038/s41597-024-02984-z
- BUS-UCLM version 3: https://doi.org/10.17632/7fvgj4jsp7.3 ; paper: https://doi.org/10.1038/s41597-025-04562-3

Raw images, masks, patient records and fitted pickle/joblib models are not distributed in this code release. Do not upload credentials or dataset copies to this repository. Dataset permissions remain those of the original providers.

## Contents and execution order

1. `notebooks/bus-bra.ipynb` and `notebooks/breast-cancer.ipynb` preserve the original exploratory and development code. Outputs and notebook metadata were cleared for release. These are research notebooks, not a single automated command.
2. `archived_pipeline/bus-compare/bus_v6_features_*/executed_cell.py` and its `v6_extractor.py` contain the frozen V6 extraction code.
3. The V6 external-training directory contains `training_cell.py`; `bus_uclm_external_*/executed_cell.py` evaluates the selected BUS-UCLM subset.
4. `archived_pipeline/bus-v14/bus_uclm_contour_*/executed_cell.py` performs contour perturbation. The V11 directory contains the archived contribution-plot builder.
5. `scripts/revision_analysis.py` computes the R17 CPU supplements from archived feature/prediction packages. It does not refit diagnostic classifiers.
6. `scripts/r18_stability.py` refits the source pipeline with split seeds 42–46 and fixed model seed 42. No best split is selected.

## Environment

Use Python 3.11 and install `pip install -r requirements.txt`. `environment-recorded.json` records the available R18 run versions; requirements are not a complete lockfile. Archived notebooks may also use CatBoost, XGBoost, LightGBM or TabICL; install those only for the corresponding exploratory comparator cells, using their recorded notebook configuration. The repository was assembled from executed archives; a fresh raw-data-to-all-figures run has not been validated for this portable release.

## Inputs and paths

Archived scripts retain their original Kaggle paths (`/kaggle/input`, `/kaggle/working`) and dataset discovery logic. Configure mounts and inspect each script's path block before running. Original downloaded archive layouts must be adapted to the notebook loaders.

R17 supports `BUS_INPUT_ROOT`, `BUS_OUTPUT_ROOT` and `BUS_BOOTSTRAPS` (default 2000). Its input root must contain extracted archived packages named `bus_v6_features_*` (features.csv, cohort.csv, quality.csv), `bus_v6_external_training_*` (external_predictions.csv), `bus_uclm_external_*` (predictions_with_labels.csv, cohort_frozen.csv, features.csv, quality.csv), `bus_uclm_contour_*` (perturbed_features.csv, extraction_status.csv, all_predictions.csv), and `interpretability_v11` (build.py and contribution tables). These derived inputs must be generated by the preceding pipeline or supplied from the matching analysis archive; downloading raw images alone is not sufficient to run R17.

R18 searches for the V6 feature and previous training packages. See its `FEATURE_PATH` and `PREVIOUS_RUN_PATH` settings. Preserve all images from the same patient in the same development partition. BUS-UCLM patient IDs are dependence clusters, not a single patient diagnosis.

## Interpretation

This is retrospective exploratory research using supplied masks. BrEaST descriptors and BUS-UCLM eligibility images were inspected during the research process. External model fitting was not performed, but these are not wholly untouched validations of the research process. Repeated split variability is descriptive and does not provide independent external replications. Small nonsignificant diagnostic increments do not establish equivalence. Contour perturbation does not establish interobserver or test–retest reliability.

## Measurable-case paired analysis (2026-11-01 release)

`run_complete_cases.py` is the archived analysis used for the added measurable-case comparisons in the JMU manuscript. It uses frozen predictions and performs no model training. Place the matching `evidence/` directory next to this script, using these required layouts:

- `evidence/bus_v6_features_*/features.csv` and `cohort.csv`
- `evidence/bus_v6_external_training_*/external_predictions.csv`
- `evidence/bus_uclm_external_*/predictions_with_labels.csv`, `features.csv`, and `descriptive_subgroups.csv`

These are derived inputs from the archived feature/prediction pipeline; raw image downloads alone are insufficient. This release does not include row-level inputs or raw images. Generate the matching inputs from the archived pipeline, or use the matching retained analysis archive. Avoid mixing results from different model versions. The script deliberately retains its original input layout and writes to `new_results/` beside itself.

Run from this directory after installing the requirements:

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python run_complete_cases.py
```

The script asserts 170 measurable BrEaST cases and 142 BUS-UCLM images, preserves paired comparisons and uses 2,000 bootstrap replicates (seed 20261031). BrEaST uses diagnosis-stratified case resampling; BUS-UCLM uses patient-cluster resampling with image-equal and patient-equal weighting. Confidence intervals are conditional on frozen fitted models. `results/complete_cases/` contains archived aggregate metrics, paired increments, protocol and verification records from the completed analysis, not a claim of a new rerun for this packaging update. Identifiers and individual predictions are excluded from this public package.

The 2026-11-01 packaging check verified the copied script against the retained analysis archive and compiled the Python syntax. It did not rerun training or the bootstrap analysis. `RELEASE_SHA256.txt` records the current release bytes; the older `SOURCE_SHA256.txt` is the historical source-provenance manifest.
